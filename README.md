# pair-wise-yf-47 城市轨道交通突发停运应急协同

源提示词摘要：调度员、车站值班员、公交接驳负责人和客服主管协同处理突发停运，维护事故时间线、区段与车站状态、接驳计划、跨岗位确认和对外口径；弱网时需要使用缓存并把操作放入本地队列。

## 技术栈

Next.js15、TypeScript、App Router、Ant Design、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62012

## 外部推送事件对账（事件对账面板）

- **入账幂等**：线网中心的区段停运/预计恢复推送按外部编号入账，同一编号重复推送只记日志、不重复入账。
- **本地为准**：入账时比对本地车站现场状态与接驳计划，对不上生成「现场状态不一致 / 接驳计划不一致」差异，只留痕不回写本地。
- **恢复结论联动**：预计恢复推送在无差异时形成有效恢复结论；本地车站状态一旦变化，命中区段的结论立即作废（时间线留痕）。
- **断网队列**：断网期间推送先暂存本地收件箱；回网自动按外部编号合并（收件箱内先去重、已入账的丢弃、未入账的继续重试入账），也可手动重试。
- **先到先得**：调度台认领区段按请求到达时刻做 CAS 裁决，与处理顺序无关；「两台同时认领」按钮模拟并发，只让先到的生效。

纯领域逻辑在 `lib/reconcile.ts`，可用 `npx tsx scripts/verify-reconcile.ts` 跑 19 条规则断言。
